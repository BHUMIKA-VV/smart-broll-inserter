# Accessing Ready-Made Talking Head Datasets

This guide provides specific instructions for accessing the major talking head video datasets.

## ⭐ Top Recommended Datasets

### 1. **TalkVid** (Large, Modern, Open)
- **GitHub**: https://github.com/FreedomIntelligence/TalkVid
- **Size**: ~1,244 hours, 7,729 speakers, HD/4K
- **Languages**: 15 languages
- **Access Steps**:
  1. Visit the GitHub repository
  2. Check the README for download links
  3. May require:
     - Academic email or research affiliation
     - Agreement to terms of use
     - Registration or request form
  4. Download instructions are usually in the repository

### 2. **THVD (Talking Head Video Dataset)**
- **Papers with Code**: https://paperswithcode.com/dataset/thvd
- **Size**: ~47,547 videos, ~2.7 TB, 20k+ identities
- **Resolution**: 4K / 1080p
- **Duration**: 20 seconds to 5 minutes
- **Access Steps**:
  1. Visit Papers with Code page
  2. Look for "Download" or "Access" links
  3. Check the original research paper for:
     - Dataset website URL
     - Contact information for access requests
     - Academic access requirements
  4. Many academic datasets require:
     - Research purpose statement
     - Institutional affiliation
     - Agreement to terms

### 3. **SpeakerVid-5M**
- **Size**: 5.2M clips, ~8,743 hours
- **Content**: Monologue, listening, dyadic conversations
- **Access Steps**:
  1. Search for the research paper on SpeakerVid-5M
  2. Check paper's "Data Availability" section
  3. Look for:
     - Dataset website
     - GitHub repository
     - Contact email for access requests
  4. Usually requires research/academic access

## Quick Access Methods

### Method 1: Check GitHub Repositories
Most modern datasets have GitHub repos with:
- Download links
- Sample videos
- Access instructions
- Terms of use

**Search for**: `[Dataset Name] github`

### Method 2: Check Papers with Code
1. Go to https://paperswithcode.com/
2. Search for the dataset name
3. Look for "Download" or "Get Dataset" links
4. Check associated papers for access info

### Method 3: Contact Dataset Authors
1. Find the research paper introducing the dataset
2. Look for author contact information
3. Email requesting access (if academic/research use)
4. Include:
   - Your affiliation
   - Research purpose
   - Agreement to terms

## Alternative: Free Stock Videos (No Access Required)

If you need videos immediately without access procedures:

1. **Pexels**: https://www.pexels.com/videos/
   - Search: "interview", "presenter", "talking head"
   - Free, no attribution required

2. **Pixabay**: https://pixabay.com/videos/
   - Search: "person speaking", "interview"
   - Free for commercial use

3. **YouTube Creative Commons**
   - Filter by Creative Commons license
   - Use yt-dlp to download (check license first!)

## Sample Video Requirements for Smart B-roll Inserter

**A-roll (Talking Head)**:
- ✅ Must have audio track with speech
- ✅ Duration: 30-90 seconds (recommended)
- ✅ Format: MP4, MOV, AVI, MKV, WebM
- ✅ Resolution: 720P or higher

**B-roll Clips**:
- ✅ Can be silent (no audio required)
- ✅ Duration: 5-20 seconds each
- ✅ Multiple clips (6+ recommended)

## Notes

- Academic datasets often have research-only restrictions
- Large datasets (TB size) may require significant storage
- Some datasets provide sample/preview videos for testing
- Always check and comply with licensing terms
- For commercial use, ensure proper licensing
